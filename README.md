# HUCK - Ultimate Frisbee

A 3D ultimate frisbee game that runs in the browser. Play 3v3 all the way up to 10v10, open packs, star up your players (0-5 stars), build your own team, use the auction house, and run a league season with playoffs.

Play: https://treyblade9to10-eng.github.io/huck/

Built with three.js (MIT, vendored in `js/lib`). Everything saves in your browser. Coins only come from playing - no real money.
